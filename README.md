# Java Hello World Program

##  About the Project

This is a simple Java program that displays "Hello, world!" on the console.

It was created as part of my initial Java programming practice to understand the basic structure and execution of a Java program.

##  Technologies Used

- Java

##  Concepts Used

- Java Class
- Main Method
- System.out.println()
- Basic Program Structure

##  How to Run

**Prerequisite:** Install JDK on your system.

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project in your Java IDE.

3. Compile the program:

   ```bash
   javac Sum.java
   ```

4. Run the program:

   ```bash
   java Sum
   ```

##  Expected Output

```text
Hello,world!
```

##  Learning Outcome

Learned the basic structure of a Java program and how to display output using the `System.out.println()` statement.
